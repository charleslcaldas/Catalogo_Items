=== SNAPSHOT DO SCHEMA: potenciais ===
## Collection: potenciais (base)

### Fields
- numero_potencial: text (required)
- cliente: text (required)
- status: text (required)
- created: autodate triggers: onCreate
- updated: autodate triggers: onCreate,onUpdate
- observacoes: text
- nome_potencial: text
- proprietario: text
- nome_comprador: text
- notas: text
- anexos: file
- estagio_id: relation → estagios_potencial
- incoterm_cliente: text
- condicao_pagamento_cliente: text
- tempo_fabricacao_cliente: text

### Indexes
- CREATE UNIQUE INDEX idx_potenciais_numero ON potenciais (numero_potencial)
- CREATE INDEX `idx_potenciais_nome` ON `potenciais` (nome_potencial)
- CREATE INDEX `idx_potenciais_proprietario` ON `potenciais` (proprietario)
- CREATE INDEX `idx_potenciais_estagio_id` ON `potenciais` (estagio_id)

### API rules
- list: @request.auth.id != ''
- view: @request.auth.id != ''
- create: @request.auth.id != ''
- update: @request.auth.id != ''
- delete: @request.auth.id != ''

### Related collections
- estagios_potencial(nome text, cor_hex text, ordem number, created autodate, updated autodate)
